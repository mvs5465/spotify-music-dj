# Spotify Music DJ - Claude Code Guidelines

## Project Overview
A localhost AI-powered Spotify DJ app that learns user music preferences through interaction history.

## Key Features
- Claude AI integration for intelligent song selection
- User preference tracking (plays, skips, upvotes, downvotes)
- Full Spotify playback control
- Preference-aware recommendations

## Development Guidelines

### Stack Decisions
- **Frontend**: TBD (React recommended for interactivity)
- **Backend**: TBD (Node.js recommended for Claude API + Spotify integration)
- **Database**: Local (JSON or SQLite) for preference tracking

### Before Major Work
- Confirm tech stack choices
- Plan API integration architecture
- Outline preference tracking schema

### GitHub Operations
- Use `gh` CLI for all GitHub operations
- Commits when significant features complete
- Push to main after confirmation

### Communication
- Keep explanations brief and focused
- Use bullet points for clarity
- Lead with the answer
