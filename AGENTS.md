# Spotify Music DJ

## Project Overview
A localhost AI-powered Spotify DJ app that learns user music preferences through interaction history.

## Key Features
- AI-assisted song selection
- Preference tracking for plays, skips, upvotes, and downvotes
- Spotify playback control
- Preference-aware recommendations

## Development Guidelines
- Confirm tech stack choices before major implementation.
- Plan the API integration architecture before building.
- Outline the preference-tracking schema early.

## Recommended Stack
- Frontend: React
- Backend: Node.js
- Database: local JSON or SQLite

## GitHub
- Use `gh` for GitHub operations.
- Commit when significant features are complete.
- Confirm before pushing to `main`.
